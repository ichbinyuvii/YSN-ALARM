# YSN Smart Alarm

A browser-based alarm experience with timer and stopwatch tools, multiple themes, and configurable wake-up missions.

![YSN Smart Alarm interface](https://yuvrajsinghnegi.vercel.app/images/projects/ysn-alarm.webp)

## Live demo

[Open YSN Smart Alarm](https://ichbinyuvii.github.io/YSN-ALARM/)

## Features

- Create alarms with labels, repeat-day selection, and sound choices.
- Use timer, stopwatch, and world-clock views.
- Choose from wake-up challenges such as math, memory, typing, pattern, rapid-tap, and shake missions.
- Select from several visual themes; install as a PWA where the browser supports it.
- Responsive, single-file HTML interface.

## Run locally

Open `index.html` in a modern browser. Some notification, sound, and install behavior depends on browser permissions and platform support.
